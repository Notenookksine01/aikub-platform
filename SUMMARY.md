## 🚀 How to Use

### Quick Start
```bash
git clone https://github.com/Notenookksine01/aikub-platform.git
cd aikub-platform
npm install
cp .env.example .env
# Edit .env with Facebook credentials
npm run build
npm start
```

### Key Commands
- `npm start` - Run the platform
- `npm test` - Run tests
- `npm run build` - Build for production
- `npm run lint` - Check code quality
